Outrun is a multiplayer sidescroller built in Unreal Engine 5, using a combination of C++ and blueprints.

A link to the full presentation highlighting key aspects of the game can be located on the following link:

https://youtu.be/pd_HowBafts

Developers:

Ian Corkill
Harvey Palmer
Max Evans

This game was made as part of our Advanced Game Engines module during our final year of University.
It utilises local multiplayer gameplay and allows the user to use a mouse and keyboard for player one and an XBox controller for player two.

The game utilises a save and load system, collectables, shooting, advanced character movement including wall jumps and grabbing, and a sophisticated level design to immerse the user in a dark and forboding labyrinth.
